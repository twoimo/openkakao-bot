# openkakao-bot

Private snapshot of the KakaoTalk macOS auto-reply agent.

The beginner guide, including **which KakaoTalk tables you need**, is in the Korean [README.md](README.md).

This repository contains source code only. It does **not** include:

- KakaoTalk local chat databases
- the vector/memory database
- credentials or runtime queues

Those files stay on your Mac. See README.md for the table list (`NTChatRoom`, `NTChatMessage`, `NTUser`, `NTChatMeta`, `NTOpenLink`) and the paths the agent creates locally.
