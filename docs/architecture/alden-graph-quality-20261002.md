# Alden 0.3.4: 방 이름과 검색 품질

공개된 역사 코퍼스의 1,181개 방 중 213개는 제목이 비어 있었다. 기존 그래프의 40개 방 중 23개가 같은 `이름 없는 채팅방`으로 보인 원인이다. 제목이 없는 방도 실제 방이므로 기록을 삭제하거나 이름으로 합치지 않는다.

## 변경과 근거

- 계정·방·발신자 숫자 ID를 계속 사용한다. 확인된 등록 제목은 해당 방 ID에만 적용한다. 나머지는 `제목 미확인 · #고유표식`으로 구별하고 제목을 추측하지 않는다.
- NFKC, 공백과 보이지 않는 제어 문자를 표시·검색 이름에 정규화한다. 원문과 원본 이름은 코퍼스에 보존한다. 같은 이름과 띄어쓰기 변형은 검색 별칭이며 동일한 방이나 사람이라는 증거로 사용하지 않는다.
- 동일 표시 이름인 방은 표식을 붙인다. 공유 이름을 음성으로 요청하면 임의의 방을 고르지 않고, 표시 이름 전체를 선택하면 해당 방으로 구분한다.
- 시스템·손상된 발신자 식별자를 인물로 만들지 않는다. 평가 데이터도 양수 방·메시지 ID, 64비트 범위, 숫자 표현, 중복 원문 ID와 발신 역할을 검사한다. 출시한 코퍼스의 원문 중복 키는 `(chat_id, log_id)`다.
- 방 제목과 근거를 같은 읽기 전용 스냅샷에서 읽는다. 직접 색인 경로의 약 1.9GB 복사본 42회 생성이 1회로 줄었다. 전체 색인 주기는 원래부터 하나의 스냅샷을 공유하므로 두 경로의 수치를 분리했다.
- 인물의 최신 수집 순서 표본은 기존 결과를 유지하면서 `(author_id, chat, id)` 색인을 이용해 방별 후보를 합친다. 인물의 전체 메시지를 정렬하는 비용을 줄였다.
- 기본 시드의 역사적 방 범위를 복원한다. 기간을 지정하면 해당 원문을 먼저 제한하며 REAL 시간의 원본 값과 ISO 표현을 함께 보존한다.
- 질문에 명시된 두 주제는 그래프에서 연결돼 있지 않아도 최종 맥락에 유지한다. 공유 별칭으로 임의의 이웃을 확대하지 않는다. 인용문과 근거 배열을 같은 슬라이스로 제한한다.

## 같은 장치에서의 색인 비교

각 조건 3회, 중앙값이다. 공개된 동일 역사 코퍼스를 읽어 비공개 임시 그래프만 썼다. 원본 카카오 DB, 권한, 전송, 모델은 변경하지 않았다.

| 측정 범위 | 0.3.3 | 0.3.4 | 감소율 |
| --- | ---: | ---: | ---: |
| 방 직접 색인 | 59.794초 | 1.857초 | 96.89% |
| 인물 직접 색인 | 3.058초 | 1.191초 | 61.06% |
| 공유 스냅샷 안의 방·인물 단계 합계 | 3.228초 | 2.382초 | 26.22% |
| 위 단계와 스냅샷 복사 합계 | 3.892초 | 3.518초 | 9.60% |

공유 스냅샷 안의 방 단계만 보면 1.514초에서 1.666초로 증가했다. 인물 단계의 개선과 구분해 기록한다. 전체 원본 수집·주제 집계·임베딩·OSK·화면 갱신 지연을 이 숫자로 대신하지 않는다. 콜드 스타트나 전력 절감 주장도 아니다.

100개 표본 노드의 ID 집합과 근거 검증을 유지했다. 공통 `이름 없는 채팅방`과 동일 방 표시 이름 그룹은 각각 23개와 1그룹에서 0으로 줄었다. 등록 제목이 있는 3개 방은 복원하고 나머지는 미확인 상태를 표시한다.

## 검색 평가

[고정 평가 결과](alden-retrieval-v2-20261002.md)와 [상세 JSON](alden-retrieval-v2-20261002.json)은 합성 방·동명이인·미지의 방·기간·REAL 시간·서로 떨어진 비교 주제를 포함한 27문항이다. 조정용 12문항과 검증용 15문항을 분리했다. 실제 로컬 E5와 제품의 공개 검색 함수를 사용했으며 모델이 자기 응답을 정답으로 승인하지 않았다.

81개 조합을 조정용 문항으로 선택한 결과 가중치 1:1, RRF k=60, 후보 40개, 인용문 8,000자의 기본값이 유지됐다. 검증용 문항의 최종 맥락 회수율은 1.0이고 최종 맥락의 금지 방 혼입은 0이었다. 전체 27개 새 공개 요청의 지연은 p50 23.250ms, p95 27.404ms다. 작은 합성 그래프의 수치이며 설치 UI나 실제 트래픽의 백분위가 아니다. 조정 격자는 정확히 같은 E5 출력을 재사용하므로 그 지연을 새 질의 지연으로 보고하지 않는다.

철회되지 않은 오래된 별칭 후보 1개는 충분한 대체·정체성 근거가 없어 삭제하지 않았다. 해당 순위 부정 사례와 BM25 단독 경로의 약점은 평가에 남아 있다. 최종 맥락의 누출 0건을 모든 후보 순위의 완전성으로 확대하지 않는다.

## 검증과 전달 상태

소스 필수 Python 검사 1,143개 중 27개 건너뜀, 실패 0; 네이티브 검사 91개, UI 검사 211개와 clippy를 통과했다. 첫 전체 검사에서 설치 롤백 픽스처 1개가 실패했으나 단독 재현과 전체 재검사는 통과했다. 이후 진단을 남길 수 있게 픽스처의 오류 출력도 추가했다. 실제 설치 롤백이 발생했다는 뜻은 아니다.

[검색 시퀀스](graphrag-search-sequence.html)는 Archify showcase 9개 검사와 4개 데스크톱 크기의 브라우저 검사를 통과했다. 1440×900 밝은 화면과 2048×1320 어두운 화면을 별도로 시각 검토했다. 고정 뷰어 UI는 영어이며 작성한 설명은 한국어다.

설치와 OSK 반영, 원격 CI 및 릴리스 자산 대조는 별도 전달 기록으로 확인한다. 역사 코퍼스의 정상 검색은 최신 원본 수집을 증명하지 않는다. 원본 앱 데이터 접근 승인, 사람의 음성·wake·실제 재생·물리 단축키·Retina, Developer ID·공증과 프로덕션 전환 승인은 아직 남아 있다.
