# Alden 0.3.11 설정 5페이지 개선

0.3.11을 설치했고 build/install36경로·deep/strict·기존5프로세스와설정보존을확인했다. 원격 CI·릴리즈 대조는 진행 중이다. 공개 화면은 모두 예시 데이터이며 실제 대화 캡처는 private 디렉터리에 보관한다.

## 확인한 문제와 수정

| 순서·페이지 | 발견한 문제 | 적용한 동작 | 검증 범위 |
|---|---|---|---|
| 1 지식 그래프 | 제목과 노드 라벨 겹침, 좁은 창의 노드 잘림 | resize 때 overlay 경계를 캐시하고 투영 경계로 전체 보기 카메라 거리를 계산 | 예시640×680·1200×760, 실제 OSK 탐색·뒤로/전체 보기 |
| 2 카카오톡 대화 | 첫 화면 공백, 끝 메시지 잘림, 실제 시스템 행 조회 실패와 큰ID 반올림 위험 | 최근 유효방 자동 선택, ID 문자열 전달, 최신 메시지 고정·오류 재시도, 시스템 알림 원문 접기 | UI 회귀, 실제 CLI100메시지, private native default/min |
| 3 음성 대화 | 마이크 동선이 설정 안에 있음, 재진입 뒤 기록 갱신 누락 | 같은 페이지에 마이크·진짜 준비 상태, 최신 세션·중복 없는 갱신 | 저장된 예시 기록·빈 native 기록; 물리 음성은 미검증 |
| 4 기억 정리 | DB 기술명, 과거 단계가 계속 진행으로 보임 | 쉬운 이름·짧은 단계명, 현재 상태와 시간별 과거 기록 구분 | 예시·실제 수집 집계 |
| 5 설정 | 페이지별 밝은/어두운 색 혼재, 숨겨진 저장 결과 | 공통 navy 토큰, 간격 축소, draft 보존, readback 성공 때만 편집 종료 | UI draft/save/uncertain-write 회귀·실제 등록목록 |

5페이지의 제목·현재 상태·내용·행동 순서를 유지하고 중복 topbar를 없앴다. sidebar180px/좁은창145px·40px navigation과 기존 keyboard 동선을 유지한다. 새 진단 대시보드를 제품 화면에 넣지 않았다.

## 같은 조건의 정보 밀도

같은1200×760 브라우저·합성 방1000메시지·최근100건을 비교했다(n1). 이전6e7022c와 수정 소스를 별도 서버에서 읽었다.

| 지표 | 이전 → 수정 | 변화 |
|---|---:|---:|
| 본문 너비 | 753 → 775px | +2.92% |
| 본문 높이 | 549.5625 → 636.15625px | +15.76% |
| 본문 면적 | 413,820.563 → 493,021.094px² | +19.14% |
| 완전히 표시되는 메시지 | 4 → 6 | +50% |
| 마지막 메시지 완전 표시 | 아니오 → 예 | 잘림 수정 |

면적 증가율은 `(775×636.15625/(753×549.5625)-1)×100`이다. 메시지 개수 증가는 `(6/4-1)×100`이다. 앱 처리량·LLM 정확성·전력 개선율이 아니며 모든 대화 길이에 일반화하지 않는다. [측정 원자료](alden-sidebar-audit-20261003/density-comparison.json).

전체 보기의 노드 중심p와 최대 glyph 반경r를 포함하여 `d ≥ p.z+r+max((|p.x|+r)/tan_x,(|p.y|+r)/tan_y)`를 만족하는 카메라 거리를 구한다. 화면 비율과 라벨 여백을 tan에 반영한다. 계산은 resize/탐색 전환 때만 수행한다. Projection 회귀2개와 최소창 렌더로 확인했다.
