# Alden 0.3.3 — decoder cancellation and Korean speech

The qwen-tts 0.1.1 wrapper accepts arbitrary generation kwargs, but its internal forwarding dictionary omits stopping criteria. Alden now attaches a per-call criterion to the owned talker decoder, preserves existing criteria, and restores the method in `finally`. A private lock serializes synthesis and disposal so hooks cannot leak between concurrent turns. Unsupported decoder layouts fail before synthesis. Neither SDK files nor model weights are patched.

Actual source adapters loaded Qwen3-TTS 1.7B BF16 on MPS. Three local turn cancellations returned 14.483/23.487/16.434 ms after cancellation inside decoding, at decoder step 2. A separate global epoch stop returned in 19.552 ms, preserved the prior WAV, remained latched until a private test resume, and then synthesized a new reply. With probe-owned model references dropped before close, allocated MPS memory read back 0 bytes. The earlier local probe retained engine references and therefore cannot establish disposal memory. These are four native decoder observations, not physical-hotkey latency, microphone barge-in, cold-model cancellation or percentile estimates.

The previous installed 0.3.2 first WAV took 41.918 s in TTS and failed independent Whisper content readback. Official [Qwen speaker guidance](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice) identifies Ryan as an English-native male voice and Sohee as a Korean-native female voice, and recommends native-language use for quality. The model checkpoint and BF16 precision remain unchanged; the 0.3.3 default explicitly selects Sohee with a restrained, gender-neutral Korean instruction.

Changing integer words to native Korean alone passed only 2/6 exact ASR checks. A same-weight, same-instruction comparison found Ryan generated some unexpectedly long short-number clips; Sohee's six clips were 0.88–1.36 s, but two exact ASR results remained ambiguous. Disabling sampling also failed an earlier candidate. The selected approach marks standalone integer replies as numbers for speech only: visible/conversation `12입니다.` is spoken as `숫자는 십이입니다.`. Other text, dates, leading-zero identifiers, decimals and negative values remain unchanged.

The selected speaker and numeric cue passed 6/6 development readbacks for 4/12 across three new seeds. After removing the male instruction, eight separate held-out source cases covered 7, 21, 99, 1234, 0, meeting time, decimal value and negative temperature. Seven exact ASR results matched; 21 was formatted as the homophone `20일`. The audio requires human review for that ambiguity. ASR text matching is an independent check, not a substitute for listening or general voice-quality proof. Generation settings remain sampled; no fixed-decoding shortcut is credited as a quality fix.

Focused voice/model checks and the configured Python suite passed: 111 focused tests with 5 skips, 1,134 configured tests with 27 skips, no failures. The 0.3.3 bundle build passed. Installation, exact-commit CI and release receipts must be checked separately before delivery is claimed. The [voice cancellation diagram](alden-voice-cancellation.html) describes the updated synthesis/playback boundary; its viewer UI remains English with Korean authored labels.

Human wake/microphone/room audio, echo quality, physical stop/resume, first-playback latency, Retina/primary UI, approved live Kakao collection and signed production delivery remain separate work. This source progress does not close the full objective.
